Migrate the user interface components of fdm-app from Radix UI to Base UI, which is better maintained. Menus, dialogs, selects, comboboxes, popovers and other controls look and behave slightly differently, and the crop, fertilizer and soil analysis forms get searchable select fields. Tailwind class names are now merged with the `cn` package instead of `clsx` and `tailwind-merge`. The design notes describe Base UI instead of Radix UI.
