New package: a Model Context Protocol (MCP) server for AI assistants, run as its own service. It serves stateless Streamable HTTP at `/mcp`, authenticates with the same API keys as the REST API (`X-API-Key` or `Authorization: Bearer`, with a `WWW-Authenticate` challenge on 401), records changes in the audit log with channel `mcp`, and shares the per-key rate limits of the REST API. It checks the API key before it reads a request body, counts every non-tool message of a batch in the general rate limit, and waits for running requests on shutdown. Tools run the fdm-api operations, with annotations (updates and deletes are marked destructive), output schemas, cursor paging and errors the model can act on. It also offers resource templates for farms and fields, server instructions, and optional PostHog MCP analytics that never send tool arguments, results or error messages (the assistant's stated intent is sent as free text). It offers about 65 tools for farms, farm groups, fields, cultivations, harvests, fertilizers and their applications, soil analyses and soil data, measures, organic certifications, derogations, grazing intentions, catalogue search and calculations (nitrogen and organic matter balances, fertilization norms, doses, nutrient advice and soil quality indicators). Related operations share one tool with a scope argument, for example a field or a farm. Every REST operation is covered by a tool or listed as a deliberate exclusion with a reason, and a test enforces this.
