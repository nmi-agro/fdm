Added message attachment functionality in the helpdesk. Users can add attachments while they create a ticket or write a new message. Ticket assignees and senders also see any attachments in the new message email notifications. Accepted attachment types include XML and SVG files, detected via their content rather than their file extension. Agents are exempt from the regular 5-attachment limit.
