Redesign the sign-in page. The page now opens with what the app offers ("Inzicht in bodem, nutriënten en emissies") next to the sign-in card, and a header with the manual and sign-in stays visible while scrolling. The sections lead with the insights (balances, usage norms and advice, soil quality, atlas, fertilizer plan) and put data entry after them. The copy says plainly which data can be imported (fields, soil analyses) and which is entered by hand (fertilization, harvests). Features the page did not mention are added: the timeline, the organic matter balance, the phosphate balance (marked as experimental), dairy cattle and grazing, the fertilizer plan PDF, Gerrit, organizations, the API and AI assistants (MCP), plus an overview of the calculation models and data sources. The welcome e-mail is rewritten in the same style: it explains how to start (create a farm, import fields, upload soil analyses, enter fertilization and harvests), links to the manual and describes inviting an advisor or an organization. On phones the sign-in card comes first, and the cookie banner is more compact there so it no longer covers the sign-in form.
