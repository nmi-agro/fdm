Show the nitrous oxide (N₂O) emission on the nitrogen balance of an organization, a farm and a field: a card "Lachgasemissie" in kg N/ha with the CO₂-equivalent next to the card "Nitraatuitspoeling", an N₂O bar in the balance chart, and "Lachgas" under the emissions in "Posten" with the emission from fertilizers, crop residues and soil. The N₂O emission now counts in the balance; the nitrate leaching card is marked as not part of the balance. The balance chart now also stays readable on phones. All values on the nitrogen and organic matter balance pages, including the chart tooltip and the difference from the organization average, use Dutch number formatting: whole numbers, with one decimal for a value between 0 and 5 that is not a whole number, so that a small value such as an N₂O emission does not show as 0, and without a minus sign for values that round to zero. In development, a change to the calculator code updates the calculator version, so cached calculations of the old code are not reused. The impact preview of the bulk fertilizer page keeps the RVO fertilizer type of a newly added fertilizer. The manual explains how the N₂O emission is calculated.
