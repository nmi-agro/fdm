New Maatregelencatalogus in the measures section of a farm, at `/farm/:b_id_farm/:calendar/measures/catalogue` and opened with the "Maatregelencatalogus" button next to "Wat is BLN3?" on the measures page. It is a searchable list of all soil measures with filters on status, effect type, costs (laag, gemiddeld, hoog) and theme, sortable by name, code or "Meest aanbevolen" (most recommended fields first; while the recommendations load or when they are unavailable, the option and the result line say so and the list stays alphabetical); `/` jumps to the search. Each measure shows its cost level, the themes it affects, and on how many fields of the farm it is applied (check mark), recommended (green sparkles, as in the recommended measures of the measures page) or applicable (open ring) in the selected year; the status filter shows how many measures have each status. Recommended and applicable use the same NMI calls and rules as the measures page.

The catalogue renders right away and loads the status per field afterwards; the BLN3 scores load in parallel with the applicability, and a complete status is reused for two minutes while the applied measures, the fields and their cultivations stay the same, so opening several measures does not load it again each time. When the recommended or applicable measures cannot be loaded, a notice above the list says which status is missing (and for how many fields), the status filter marks it "(niet beschikbaar)", an empty result says why instead of "no measures found", and "Opnieuw proberen" loads the status again. Without an NMI API key the notice says the statuses are not available in this environment, without "Opnieuw proberen", and the measures page does not report the recommendations as failed.

The detail page of a measure starts with its description and the fields on which it is applied, recommended or applicable, each linking to the measures of that field; the list shows about five fields and scrolls for more, and can be filtered by status (kept in the link). "Toevoegen aan percelen" opens the measures page with the add dialog on this measure and the recommended fields already selected; farm-level measures explain why they cannot be added per field. The page then shows the cost level, the effect type, the references (codes in related schemes and a link to the source), the indicators the measure affects with their theme, the range of effect sizes from the catalogue and on how many fields of the farm it is recommended for each indicator, the applicability conditions as a readable table, the conflicting measures that are in the catalogue and the other variants of the same measure. "Terug naar catalogus" returns to the list with the search and filters it was opened from.

The effect types now have plain labels: "Vast effect", "Hangt af van perceel" and "Wijzigt berekening" (kwalitatief, geclassificeerd and kwantitatief in BLN). The measures page also accepts `?fields=` next to `?openMeasure=` to preselect fields in the add dialog, and its copy addresses the user as "u".

Wherever a measure is shown on a farm — the Add Measure dialog, the active measures of a field, the farm measure table and the recommended measures — an icon opens its detail page in a new tab, so the current page and any open dialog stay as they are. The search of the Add Measure dialog also looks in the summary. The farm-wide measure recommendations moved to a shared module, so the measures page and the catalogue use the same rules.

The farm-wide recommendations are stricter about missing data, also on the measures page ("Aanbevolen maatregelen") and the indicators page ("Waar te beginnen"): a field whose applicability check or BLN3 score could not be loaded is skipped instead of counted as having nothing to recommend, so when this fails for every field the recommendations are reported as unavailable. On the measures page and in the catalogue, a measure is only recommended on fields where its impact is positive.
