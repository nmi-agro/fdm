New Maatregelencatalogus in the measures section of a farm, at `/farm/:b_id_farm/:calendar/measures/catalogue` and opened with the "Maatregelencatalogus" button under "Wat is BLN3?" on the measures page. It is a searchable list of all soil measures with filters on status, effect type, costs (laag, gemiddeld, hoog) and theme, sortable by name or code. Each measure shows its cost level, the number of indicators it affects, its effect type with a short explanation, and on how many fields of the farm it is applied (green), recommended (yellow) or applicable in the selected year. Recommended and applicable use the same NMI calls and rules as the measures page. Measures that are no longer in the catalogue are hidden, unless the farm still applies them.

The detail page of a measure starts with its description and the fields on which it is applied, recommended or applicable, each linking to the measures of that field; the list shows about five fields and scrolls for more, and can be filtered by status. It then shows the cost level, the effect type, the references (IDs in related schemes and a link to the source), the indicators the measure affects with their theme and the range of effect sizes from the catalogue, the applicability conditions as a readable table, the conflicting measures that are in the catalogue and the other variants of the same measure.

Wherever a measure is shown on a farm — the Add Measure dialog, the active measures of a field, the farm measure table and the recommended measures — an icon opens its detail page in a new tab, so the current page and any open dialog stay as they are. The Add Measure dialog no longer offers measures that are no longer in the catalogue, and its search also looks in the summary. The farm-wide measure recommendations moved to a shared module, so the measures page and the catalogue use the same rules.
