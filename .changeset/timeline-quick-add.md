Added quick-add actions to the timeline Gantt view: click empty space in a field's row to add a fertilizer application, harvest, soil sample, or cultivation via a searchable command menu prefilled with that field and date; right-click a cultivation bar for direct "Bemesting toevoegen", "Oogst registreren", and "Gewas beëindigen" actions; or use the new toolbar "Toevoegen" button to add an event without first navigating to a field.
